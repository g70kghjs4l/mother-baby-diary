# 胎儿双肾盂分离严重吗  双肾盂分离是男孩吗

> 更新时间：2026-09-15 (UTC+8)

胎儿双肾盂分离严重吗 双肾盂分离是男孩吗更新时间:2022-08-23

说起双肾盂分离，很多人都会说没听说过。双肾盂的位置是肾和输尿管连接的地方，宝宝出现双肾盂分离，是一种表现症状，它是指胎儿肾里有积水的一种表现，一般积水不会超过1厘米，这属于生理性的积水，双肾盂分离又被称为双肾集合系统分离。孕妈妈在去产检的时候，在B超检查单上会表现为椭圆形的回声区，位于肾中央的位置。

​

简单点说，肾盂就是肾和输尿管连接的地方。一般来说肾盂分离如果不超过1厘米的，就是正常现象，如果胎儿在出生的时候，肾盂分离不大于16mm，也不会有太大的问题，如果分离继续增大，宝宝就需要定期复查，根据症状的发展，判断是否需要进一步的接受治疗。双肾盂分离的治疗方法有两种，一种是宫内治疗，也就是经过子宫穿刺置入导管减压，来治疗宝宝肾积水。也可以在宝宝出生之后，用手术治疗的方法。

双肾盂分离的现象大多数发生在新生儿身上，有10%也会发生在成年人身上。在新生儿身上，有90%的概率会发生在男孩身上，所以有很多人说，如果胎宝宝双肾盂分离，就是男孩。其实也不能这样绝对的说，只能说大多数情况可能是男孩。有双肾盂分离症状的宝宝，症状轻的在出生后撒泡尿就解决了这个问题，严重的是由于宝宝先天尿路问题，，所以出生后需要通过手术治疗才能解决问题。

有双肾盂分离的宝宝，一般还伴有羊水偏少的现象。肾盂分离≤7mm的，就是轻度的，≥10mm的就是重度的。而且胎儿检查有双肾盂分离的，还要结合宝宝的膀胱是否充盈，如果充盈的就等胎儿出生后排尿了再复查。胎宝宝如果出生后，需要进行手术治疗双肾盂分离的，家长们也不必过于担心，虽然手术有一定难度，但是对孩子是没有生命安全的威胁的。
